## 📖 Dokumentasi Kegiatan Workshop (Day 1)

### 1. Rangkuman Materi yang Disampaikan

#### A. Arah Strategis JTIK PNJ (2026–2030)
* **Visi Jurusan:** Menjadi jurusan bertaraf internasional untuk mendukung daya saing bangsa dalam bidang Informatika dan Komputer.
* **Tiga Mandat Utama (Misi):** 
  1. *Pendidikan Vokasi:* Menyelenggarakan pendidikan berbasis IPTEKS untuk menghasilkan lulusan berkarakter dan bertakwa.
  2. *Riset & Inovasi:* Mengembangkan penelitian terapan dan produk inovasi berkualitas.
  3. *Tata Kelola Digital:* Mengembangkan tata kelola jurusan yang efisien, efektif, dan akuntabel berbasis TIK.

#### B. Kurikulum OBE & Peluang Karier Prodi D4 TMJ
* **5 Profil Lulusan (PL) D4 TMJ:**
  1. **PL01 (Jaringan Komputer):** Merancang, mengelola, dan mengamankan jaringan (Network Engineer, Cloud Network Associate).
  2. **PL02 (Internet of Things - IoT):** Membangun dan mengintegrasikan sistem IoT (IoT Engineer, IoT System Integrator).
  3. **PL03 (Infrastruktur TI & Keamanan):** Mengelola server, cloud, dan keamanan siber (System Administrator, Security Engineer).
  4. **PL04 (Pengembangan Aplikasi):** Merancang aplikasi web & mobile interaktif (Web/Mobile Developer, Full Stack Developer).
  5. **PL05 (Technopreneur Internet & IoT):** Merintis dan mengomersialisasikan bisnis berbasis digital/IoT (Startup Founder, Product Builder).
* **Struktur Kurikulum (144 SKS - 8 Semester):**
  - *Semester 1–2 (Fondasi):* Dasar jaringan komputer, algoritma pemrograman, matematika diskrit, sistem operasi, aljabar linear, dan piranti komputer.
  - *Semester 3–4 (Pengembangan):* Jaringan server, sistem embedded, pemrograman web, keamanan cloud, kriptografi, dan sistem terdistribusi.
  - *Semester 5–6 (Spesialisasi):* Wireless Sensor Network (WSN), AIoT, pemrosesan citra digital, visi komputer, dan manajemen proyek TIK.
  - *Semester 7–8 (Magang & TA):* Magang Industri/PKL di industri (15 SKS pada Sem 7) dan Penyusunan Skripsi (6 SKS pada Sem 8).

#### C. Program MBKM, MSIB, & Strategi Belajar
* **MBKM & MSIB:** Memberikan hak belajar hingga 2 semester di luar prodi/kampus (dikonversi hingga 20 SKS per semester) melalui Magang Bersertifikat dan Studi Independen.
* **Metode Pembelajaran:** Menggunakan pendekatan *Project-Based Learning (PjBL)*, *Problem-Based Learning (PBL)*, dan *Case-Based Learning (CBL)*.
* **Strategi Belajar (Make It Stick):** Menggunakan *retrieval practice* (uji diri), *spaced practice* (jeda waktu belajar), *interleaving* (mencampur topik), dan *elaboration* (menjelaskan ulang).

#### D. Materi Workshop: Git, GitHub, & AI (Nugi Farhan - Senior Product Designer)
* **Building with AI & Prompt Engineering:**
  - *Prompt:* Instruksi/masukan kepada model AI untuk mendapatkan hasil tertentu.
  - *Struktur Prompt:* Memuat **Role** (peran AI), **Task** (tugas utama), **Context** (latar belakang & batasan), dan **Format** (bentuk keluaran).
* **Version Control (Git & GitHub):**
  - *Git:* Sistem pelacak perubahan file secara lokal (DVCS) buatan Linus Torvalds.
  - *GitHub:* Platform cloud untuk menyimpan repository Git online dan berkolaborasi.
  - *Git Workflow:* Working Directory -> Staging Area -> Repository (.git directory).
  - *Perintah Utama:* `git init`, `git add .`, `git commit -m "pesan"`, `git remote add origin <url>`, `git push origin main`, dan `git pull`.

#### E. Tata Tertib Akademik & Penggunaan Lab TIK
* **Peminjaman Lab:** Peminjaman alat di tempat memerlukan jaminan KTM. Peminjaman alat dibawa pulang/ruangan wajib persetujuan tertulis Ka. Lab (Kalab) dan teknisi.
* **Kedisiplinan:** Wajib berpenampilan rapi dengan kemeja berkerah, sepatu tertutup, serta rambut pria rapi (tidak melebihi kerah baju dan tidak menutupi telinga).

### 2. Poin-Poin Penting & Pengetahuan Baru
* **Pentingnya Context pada AI:** AI dapat menghasilkan solusi koding yang sangat presisi jika instruksi (*prompt*) diberikan peran, batasan, serta format luaran yang jelas.
* **Penerapan Version Control di Industri:** Perintah Git dan repositori GitHub merupakan standar utama industri teknologi untuk mengelola versi kodingan serta berkolaborasi dalam tim.
* **Penguasaan Vokasi TMJ:** Keberhasilan di prodi TMJ ditunjang oleh pemahaman mendalam pada jaringan, IoT, pembuatan aplikasi, serta kepemilikan portofolio proyek nyata.
