#### D. Materi Workshop: Git, GitHub, & AI (Nugi Farhan - Senior Product Designer)
* **Building with AI & Prompt Engineering:**
  - *Definisi Prompt:* Instruksi/masukan yang diberikan kepada model AI untuk mendapatkan hasil tertentu[span_67](start_span)[span_67](end_span).
  - *Struktur Good Prompt:* **Role** (peran AI), **Task** (tugas utama), **Context** (tujuan & persyaratan), dan **Format/Output** (bentuk keluaran yang diinginkan)[span_68](start_span)[span_68](end_span)[span_69](start_span)[span_69](end_span).
  - *Manfaat Prompt Engineering:* Meningkatkan performa AI, mengurangi bias, serta memberikan kontrol dan hasil yang presisi[span_70](start_span)[span_70](end_span).
* **Pemahaman Git & GitHub:**
  - *Git:* Distributed Version Control System (DVCS) lokal yang diciptakan Linus Torvalds (2005) untuk melacak setiap perubahan file[span_71](start_span)[span_71](end_span)[span_72](start_span)[span_72](end_span).
  - *GitHub:* Platform cloud berbasis web untuk menyimpan repository Git secara online dan mendukung kolaborasi tim[span_73](start_span)[span_73](end_span).
  - *Siklus Git Workflow:* **Working Directory** (tempat edit file) $\rightarrow$ **Staging Area** (menyiapkan perubahan) $\rightarrow$ **.git Directory / Repository** (menyimpan histori commit secara permanen)[span_74](start_span)[span_74](end_span).
* **Perintah Penting Git (Essential Commands):**
  - `git init` : Menginisialisasi repository Git baru di folder lokal[span_75](start_span)[span_75](end_span).
  - `git add .` atau `git add -A` : Memindahkan seluruh perubahan file ke staging area[span_76](start_span)[span_76](end_span)[span_77](start_span)[span_77](end_span).
  - `git commit -m "pesan commit"` : Menyimpan versi perubahan file ke repository lokal[span_78](start_span)[span_78](end_span).
  - `git remote add origin <url>` : Menghubungkan repository lokal ke GitHub remote[span_79](start_span)[span_79](end_span).
  - `git push origin main` : Mengunggah hasil commit dari komputer ke repository GitHub[span_80](start_span)[span_80](end_span).
  - `git pull origin main` : Mengunduh dan menggabungkan perubahan terbaru dari GitHub ke komputer lokal[span_81](start_span)[span_81](end_span).
* **Pengaturan Keamanan SSH Key:**
  - Menggunakan algoritma enkripsi Ed25519 (`ssh-keygen -t ed25519 -C "email"`) untuk otentikasi aman antara terminal komputer dengan akun GitHub tanpa menginput password berulang kali[span_82](start_span)[span_82](end_span)[span_83](start_span)[span_83](end_span).
