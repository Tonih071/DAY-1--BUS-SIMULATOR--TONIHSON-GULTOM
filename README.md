### 2. Catatan & Rangkuman Materi Workshop (Materi Lengkap)

#### A. Arah Strategis JTIK PNJ (2026–2030)
* **Visi Jurusan:** Menjadi jurusan bertaraf internasional untuk mendukung daya saing bangsa dalam bidang Informatika dan Komputer.
* **Tiga Mandat Utama (Misi):** 
  1. *Pendidikan Vokasi:* Menyelenggarakan pendidikan berbasis IPTEKS untuk menghasilkan lulusan berkarakter dan bertakwa.
  2. *Riset & Inovasi:* Mengembangkan penelitian terapan dan produk inovasi berkualitas.
  3. *Tata Kelola Digital:* Mengembangkan tata kelola jurusan yang efisien, efektif, dan akuntabel berbasis TIK.

#### B. Kurikulum OBE & Peluang Karier Prodi D4 TMJ
* **5 Profil Lulusan (PL) D4 TMJ:**
  1. **PL01 (Jaringan Komputer):** Merancang, mengelola, dan mengamankan jaringan (Network Engineer, Cloud Network Associate).
  2. **PL02 (Internet of Things - IoT):** Membangun dan mengintegrasikan sistem IoT (IoT Engineer, IoT System Integrator).
  3. **PL03 (Infrastruktur TI & Keamanan):** Mengelola server, cloud, dan keamanan siber (System Administrator, Security Engineer).
  4. **PL04 (Pengembangan Aplikasi):** Merancang aplikasi web & mobile interaktif (Web/Mobile Developer, Full Stack Developer).
  5. **PL05 (Technopreneur Internet & IoT):** Merintis dan mengomersialisasikan bisnis berbasis digital/IoT (Startup Founder, Product Builder).
* **Struktur Kurikulum (144 SKS - 8 Semester):**
  - *Semester 1–2 (Fondasi - 40 SKS):* Dasar jaringan komputer, algoritma pemrograman, matematika diskrit, sistem operasi, aljabar linear, dan piranti komputer.
  - *Semester 3–4 (Pengembangan - 40 SKS):* Jaringan server, sistem embedded, pemrograman web, keamanan cloud, kriptografi, dan sistem terdistribusi.
  - *Semester 5–6 (Spesialisasi - 38 SKS):* Wireless Sensor Network (WSN), AIoT, pemrosesan citra digital, visi komputer, dan manajemen proyek TIK.
  - *Semester 7–8 (Magang & TA - 26 SKS):* Magang Industri/PKL di industri (15 SKS pada Sem 7) dan Penyusunan Skripsi (6 SKS pada Sem 8).
* **Proyeksi Dunia Kerja Digital (2025–2035):** Pertumbuhan profesi Keamanan Informasi naik +21%, Software Developer +10%, dan Arsitek Jaringan +8%.

#### C. Program MBKM, MSIB, & Strategi Belajar
* **Kebijakan MBKM & MSIB:** Hak belajar hingga 2 semester di luar program studi yang diakui hingga 20 SKS per semester. Program MSIB mencakup Magang Bersertifikat di perusahaan mitra dan Studi Independen Bersertifikat.
* **Metode Pembelajaran Vokasi:** 
  - *Project-Based Learning (PjBL):* Belajar lewat karya/produk nyata.
  - *Problem-Based Learning (PBL):* Belajar lewat pemecahan masalah terbuka.
  - *Case-Based Learning (CBL):* Belajar dengan menganalisis kasus nyata industri.
* **Strategi Belajar Efektif (Make It Stick):**
  1. *Retrieval Practice:* Uji diri sendiri tanpa melihat catatan.
  2. *Spaced Practice:* Belajar dalam sesi berjarak, bukan belajar semalam.
  3. *Interleaving:* Mencampur topik belajar agar terbiasa memilih strategi tepat.
  4. *Elaboration:* Menjelaskan materi dengan kata-kata sendiri.

#### D. Materi Workshop: Git, GitHub, & AI (Nugi Farhan - Senior Product Designer)
* **Building with AI & Prompt Engineering:**
  - *Definisi Prompt:* Instruksi/masukan yang diberikan kepada model AI untuk mendapatkan hasil tertentu.
  - *Struktur Good Prompt:* **Role** (peran AI), **Task** (tugas utama), **Context** (tujuan & persyaratan), dan **Format/Output** (bentuk keluaran yang diinginkan).
  - *Manfaat Prompt Engineering:* Meningkatkan performa AI, mengurangi bias, serta memberikan kontrol dan hasil yang presisi.
* **Pemahaman Git & GitHub:**
  - *Git:* Distributed Version Control System (DVCS) lokal yang diciptakan Linus Torvalds (2005) untuk melacak setiap perubahan file.
  - *GitHub:* Platform cloud berbasis web untuk menyimpan repository Git secara online dan mendukung kolaborasi tim.
  - *Siklus Git Workflow:* **Working Directory** (tempat edit file) $\rightarrow$ **Staging Area** (menyiapkan perubahan) $\rightarrow$ **.git Directory / Repository** (menyimpan histori commit secara permanen).
* **Perintah Penting Git (Essential Commands):**
  - `git init` : Menginisialisasi repository Git baru di folder lokal.
  - `git add .` atau `git add -A` : Memindahkan seluruh perubahan file ke staging area.
  - `git commit -m "pesan commit"` : Menyimpan versi perubahan file ke repository lokal.
  - `git remote add origin <url>` : Menghubungkan repository lokal ke GitHub remote.
  - `git push origin main` : Mengunggah hasil commit dari komputer ke repository GitHub.
  - `git pull origin main` : Mengunduh dan menggabungkan perubahan terbaru dari GitHub ke komputer lokal.
* **Pengaturan Keamanan SSH Key:**
  - Menggunakan algoritma enkripsi Ed25519 (`ssh-keygen -t ed25519 -C "email"`) untuk otentikasi aman antara terminal komputer dengan akun GitHub tanpa menginput password berulang kali.
